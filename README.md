🚀 ATS Resume Score Checker

An AI-powered web application that analyzes resumes against job descriptions to provide an ATS score with actionable improvement suggestions.

⚙️ Tech Stack

React.js + TypeScript (frontend)

Node.js (backend)

Tailwind CSS (UI)

Puter SDK (auth, cloud storage, AI APIs, KV store)

🔋 Features

📄 Upload resumes (PDF) and extract text securely

🤖 AI-powered ATS scoring & custom improvement suggestions

☁️ Cloud-based storage & resume management with Puter SDK

📱 Responsive, modern UI with Tailwind CSS

🌐 Live demo: ats-resume-checkerrr.onrender.com
